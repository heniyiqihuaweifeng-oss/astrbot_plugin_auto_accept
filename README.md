# astrbot_plugin_auto_accept

自动同意 QQ 好友申请、以及别人邀请机器人入群的请求；也可以选择性地自动同意「加群申请」（别人申请加入机器人所在的群）。

## 效果

- 收到好友申请 → 自动通过
  - 可选：只有验证信息命中关键词才通过
  - 可选：通过后自动发一句欢迎语
- 别人邀请机器人入群 → 自动通过
  - 可选：只有白名单里的 QQ 号发出的邀请才通过
- 别人申请加入机器人所在的群（仅当机器人是群管理员/群主时才会收到，**默认关闭**）→ 可选自动通过

未命中关键词/白名单的申请**不会被自动拒绝**，只是跳过，交由你之后在 QQ 客户端或协议端手动处理。

## 适用范围（请务必先看这里）

本插件是直接对接 aiocqhttp（OneBot v11）协议端的原始事件实现的，**只对通过 NapCat / Lagrange /
LLOneBot 等协议实现接入的 QQ 个人号生效**。QQ 官方机器人接口没有"好友申请""加群申请"这类事件，
装了也不会触发。

## 安装

1. 把整个 `astrbot_plugin_auto_accept` 文件夹放进 AstrBot 的 `data/plugins/` 目录下，
   或者直接在 WebUI 的插件管理页上传本插件的 zip 包。
2. 在插件管理页点击"重载插件"（或重启 AstrBot）。
3. 找到"自动同意好友/群请求"插件，点击配置按钮即可按需调整下面的选项。

## 配置项说明

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `accept_friend_request` | 是否自动同意好友请求 | 开 |
| `friend_request_keywords` | 验证信息关键词白名单，每行一个；命中任意一个才自动同意；留空则来者不拒 | 空 |
| `friend_greeting_enable` | 通过好友请求后是否自动发一句欢迎语 | 关 |
| `friend_greeting_message` | 欢迎语内容 | 你好呀，很高兴认识你～ |
| `accept_group_invite` | 是否自动同意"邀请机器人入群" | 开 |
| `group_invite_whitelist` | 允许邀请入群的 QQ 号白名单，每行一个；留空则来者不拒 | 空 |
| `accept_group_join_request` | 是否自动同意"加群申请"（别人申请加入机器人所在的群） | 关 |

## 管理员指令

`/autoaccept_status`（别名 `/自动同意状态`）：仅管理员可用，用来快速查看插件当前是否正常挂载、
以及主要开关的状态，方便排查"为什么没生效"之类的问题。

## 注意事项

- `accept_group_join_request` 默认关闭：一旦开启，机器人在其管理的**每一个**群里都会自动通过
  任何人的加群申请，请确认这是你想要的效果后再打开，且当前没有针对该开关的白名单过滤。
- 关键词/白名单留空表示不做任何过滤，所有请求都会被同意，请注意甄别，谨防被恶意添加好友或拉入
  垃圾/广告群。
- 如果你同时在 AstrBot 里接了多个 QQ 账号（多个 aiocqhttp 平台实例），本插件会自动对每一个都生效；
  如果是在插件已经运行之后才新增的账号，重载一次本插件即可让新账号也生效。

## 工作原理简述

AstrBot 的消息事件系统（`AstrMessageEvent`）覆盖的是"聊天消息"。好友申请、加群请求/邀请属于
OneBot v11 协议里独立的 `request` 类事件，不会经过 AstrBot 的统一消息管道。本插件拿到 aiocqhttp
协议端的原始客户端对象后，直接挂载 `request.friend` / `request.group` 监听器接收这两类事件，再
调用协议端提供的 `set_friend_add_request` / `set_group_add_request` API 完成"同意"操作。
